# DTTTI Instructor Evaluation

Formal English-only instructor evaluation portal for Dhaka Technical Teachers’ Training Institute.

- Manual batch, roster and instructor setup
- Shuffled anonymous access slips, one response per instructor
- Accessible eight-criterion questionnaire with review and N/A
- Closed-batch, minimum-five aggregate reports, CSV and printing
- Coordinator and principal roles; server-only Supabase integration

## Quick review

`npm run build`, `npm test`, then `npm run preview`. Open http://localhost:3000 and select **Explore demonstration**. All sample data is fictional and held in memory. Reload resets it. Production APIs require configuration and never store data in the filesystem.

See [product specification](docs/PRODUCT.md), [deployment guide](docs/DEPLOYMENT.md) and [QA record](docs/QA.md). No card-required service or paid dependency.
